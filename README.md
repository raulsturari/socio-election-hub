# Socio Election Hub

Construa BRASIL DATA LAB: aplicação web mobile-first para iPhone, dashboard eleitoral e sociodemográfico com TSE, IBGE SIDRA, IPEA, INEP e DATASUS. React/TypeScript/Tailwind/shadcn. Visual premium dark navy com ciano discreto. Navegação inferior fixa Atlas, Comparar, Correlações, Dados; safe area iOS, filtros em bottom sheets, mapas pinch zoom, gráficos touch, sem scroll horizontal, PWA, responsividade 375/390px. Atlas municipal com filtros ano 2018/2022/2026, candidato, UF, município, mapa, resultados, comparação histórica, dispersão renda x votação e fonte/metodologia. Banco/ingestão preparada para dados oficiais, harmonização por código IBGE e ano, proveniência. Não inventar números: estados vazios e demonstração somente quando explicitamente rotulada. Não inferir comportamento individual a partir de agregados. 2026 só resultados oficiais disponíveis. Construir primeira versão funcional e navegável, com dados reais somente quando efetivamente carregados e verificados.
